# Day 1: Building an Active Directory Home Lab
Date: 2026-11-09

## Task
Install Windows Server 2022 in VirtualBox and set it up as an Active Directory domain controller for a help desk and systems administration home lab.

## Challenges
- Several commands failed because of typos, such as a misspelled parameter name and a stray space after a hyphen.
- A password that didn't meet Windows complexity rules had to be replaced before the domain could be created.

## How I solved it
- Read each error message, found the typo, and retyped the command carefully.
- Set a password that met Windows rules, then continued.

Network setup:
```powershell
ipconfig
Set-NetIPInterface -InterfaceAlias "Ethernet" -Dhcp Disabled
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 10.0.2.5 -PrefixLength 24 -DefaultGateway 10.0.2.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" -ServerAddresses 10.0.2.5
ping 8.8.8.8
Rename-Computer -NewName DC01 -Restart
```
I recorded the current IP settings, disabled DHCP, set a static address with the router as the default gateway, and pointed the server's DNS at itself because a domain controller runs DNS. I confirmed connectivity with `ipconfig` and a ping, renamed the server to DC01, and took a VirtualBox snapshot.

Active Directory setup:
```powershell
Install-WindowsFeature AD-Domain-Services -IncludeManagementTools
Install-ADDSForest -DomainName "homelab.local" -DomainNetbiosName "HOMELAB" -InstallDns
```
I installed the Active Directory Domain Services role and created the homelab.local domain, setting a safe mode administrator password when prompted.

Verification:
```powershell
Get-ADDomain | Select Name, DNSRoot
Get-Service NTDS, DNS
dcdiag /q
```
- `Get-ADDomain` showed homelab and homelab.local.
- Both the NTDS and DNS services were running.
- `dcdiag /q` reported no problems.
- I took a second snapshot named "AD Installed".

## Skills and lessons
- Configuring a static IP, gateway and DNS from PowerShell
- Installing the AD DS role and creating a new domain with PowerShell
- Verifying a domain controller with `Get-ADDomain`, `Get-Service` and `dcdiag`
- Using VirtualBox snapshots as restore points
- Slowing down and checking each command before pressing Enter
